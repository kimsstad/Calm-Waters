# Property listing formatting

When a list item has a label followed by a second line of supporting detail (for example, Quiet hours followed by the times), wrap the supporting detail in `<span class="list-detail">`. The shared listings.css style makes this second line slightly smaller and lighter, as requested by the user. Use this convention for future listing work without changing the supplied wording.

Apply this styling only to supporting details within bullet-pointed list items. Keep standalone paragraphs, including checkout cleaning instructions, in their normal styling. Ordinary text wrapping onto another line does not make it supporting detail.
